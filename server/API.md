# REST API — база данных «Покупка билетов в театр»

Базовый адрес: `http://127.0.0.1:8080`
Авторизация: **HTTP Basic Auth** с учётными данными PostgreSQL (`postgres` / `12345678`).
Без авторизации или с неверными данными — ответ `401 Unauthorized` (заголовок `WWW-Authenticate`).
Формат данных: `application/json; charset=utf-8`.

---

## Общие точки входа

| Метод | Путь | Авторизация | Назначение |
|-------|------|-------------|------------|
| GET | `/health` | нет | Проверка живости сервера |
| GET | `/api` | да | Список ресурсов и подсказка |

## CRUD по всем таблицам

| Метод | Путь | Назначение |
|-------|------|------------|
| GET | `/api/<resource>` | Список записей |
| GET | `/api/<resource>/<pk>` | Одна запись по первичному ключу |
| POST | `/api/<resource>` | Создать запись (тело — JSON) |
| PUT | `/api/<resource>/<pk>` | Обновить запись (полностью) |
| PATCH | `/api/<resource>/<pk>` | Обновить запись (частично) |
| DELETE | `/api/<resource>/<pk>` | Удалить запись |

- Для **составного первичного ключа** значения указываются через запятую в порядке столбцов PK.
  Пример: `/api/play_genres/1,1`.
- `GET`-список поддерживает `?limit=<n>&offset=<n>` и фильтры `?<столбец>=<значение>`.
  Пример: `/api/shows?зал_id=1&limit=5`.

## Ресурсы и таблицы

| Ресурс | Таблица | Первичный ключ |
|--------|---------|----------------|
| `genres` | жанры | `id` |
| `plays` | спектакли | `id` |
| `play_genres` | спектакли_жанры | `спектакль_id`, `жанр_id` (составной) |
| `actors` | актёры | `id` |
| `actor_plays` | актёры_спектакли | `актёр_id`, `спектакль_id` (составной) |
| `halls` | залы | `id` |
| `seats` | места | `id` |
| `shows` | показы | `id` |
| `hall_passports` | паспорта_залов | `id` |

### Столбцы ресурсов

| Ресурс | Столбцы |
|--------|---------|
| `genres` | `id`, `название` |
| `plays` | `id`, `название`, `описание`, `длительность_минут`, `возрастное_ограничение` |
| `play_genres` | `спектакль_id`, `жанр_id` |
| `actors` | `id`, `фамилия`, `имя`, `отчество`, `звание` |
| `actor_plays` | `актёр_id`, `спектакль_id`, `роль` |
| `halls` | `id`, `название`, `количество_мест`, `этаж` |
| `seats` | `id`, `зал_id`, `ряд`, `номер`, `категория` |
| `shows` | `id`, `спектакль_id`, `зал_id`, `дата_время`, `базовая_цена` |
| `hall_passports` | `id`, `зал_id`, `площадь`, `высота_сцены`, `год_постройки` |

## Коды ответов

| Код | Значение |
|-----|----------|
| 200 | Успех |
| 201 | Создано (POST) |
| 400 | Неверный запрос (не JSON-объект, неизвестный столбец, нарушение CHECK/NOT NULL, неверный тип) |
| 401 | Нет/неверная авторизация |
| 404 | Ресурс или запись не найдена |
| 409 | Нарушение UNIQUE или внешнего ключа |
| 500 | Прочая ошибка базы данных |
| 503 | Нет соединения с БД |

Формат ошибки:

```json
{ "error": "Запись не найдена" }
```

## Примеры

### Проверка сервера
```bash
curl.exe http://127.0.0.1:8080/health
```

### Список ресурсов
```bash
curl.exe -u postgres:12345678 http://127.0.0.1:8080/api
```

### Чтение
```bash
curl.exe -u postgres:12345678 http://127.0.0.1:8080/api/plays
curl.exe -u postgres:12345678 http://127.0.0.1:8080/api/plays/1
curl.exe -u postgres:12345678 http://127.0.0.1:8080/api/shows?зал_id=1&limit=5
curl.exe -u postgres:12345678 http://127.0.0.1:8080/api/play_genres/1,1
```

### Создание
```bash
curl.exe -u postgres:12345678 -X POST http://127.0.0.1:8080/api/genres ^
  -H "Content-Type: application/json" -d "{\"название\":\"Оперетта\"}"
```

### Обновление
```bash
curl.exe -u postgres:12345678 -X PATCH http://127.0.0.1:8080/api/genres/11 ^
  -H "Content-Type: application/json" -d "{\"название\":\"Оперетта-2\"}"
```

### Удаление
```bash
curl.exe -u postgres:12345678 -X DELETE http://127.0.0.1:8080/api/genres/11
```

### PowerShell
```powershell
$cred = [pscredential]::new("postgres", (ConvertTo-SecureString "12345678" -AsPlainText -Force))
Invoke-RestMethod "http://127.0.0.1:8080/api/plays?limit=3" -Credential $cred
Invoke-RestMethod "http://127.0.0.1:8080/api/genres" -Method Post `
  -Body (@{ название = "Оперетта" } | ConvertTo-Json) `
  -ContentType "application/json" -Credential $cred
```
